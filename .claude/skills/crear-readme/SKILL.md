# Crear README

## Pasos
1. Lee el código del proyecto antes de escribir.
2. Crea README.md con estas secciones: Qué es · Requisitos · Instalación · Uso · Estructura.
3. Usa solo lo que existe en el código. Si algo no está, no lo inventes.
4. Escribe en español, con frases cortas.
5. Al terminar, resume qué secciones creaste.
