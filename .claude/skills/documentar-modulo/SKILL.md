# Documentar módulo

## Pasos
1. Pide o identifica la carpeta del módulo a documentar.
2. Lee sus clases públicas, métodos y tests.
3. Escribe un archivo .md con: Propósito · Clases principales · Ejemplo de uso · Limitaciones.
4. Describe solo lo que el código hace. No inventes comportamientos.
5. Al terminar, lista los métodos públicos que documentaste.
